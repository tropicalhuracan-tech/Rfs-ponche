# Reaction Force Security — Operaciones

App operativa de Reaction Force Security (mapa, turnos, reportes, finanzas y administración).

## Enlace
https://tropicalhuracan-tech.github.io/reaction-force-ops/

## Instalar en PC
Abre el enlace en Chrome/Edge → Instalar aplicación.

## Publicación (GitHub Pages)
El sitio se publica con el workflow **Deploy Pages** (`.github/workflows/deploy-pages.yml`):
HTML/JS estático, sin Jekyll. En el repo: **Settings → Pages → Source = GitHub Actions**.
Cada push a `main` valida archivos clave y despliega; también se puede lanzar a mano con *Run workflow*.
